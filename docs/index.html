Hallucination rate is the share of cases where the criteria text does not state a value and the model supplied one anyway. It is the number that matters most here and the one plain accuracy hides. Miss rate is the reverse: a value was stated and the model returned null. Intervals are Wilson 95%. With 60 examples they are wide, and no ranking inside an overlapping interval should be read as a real difference. Ground truth comes from registry metadata, which is itself imperfect — see the audit section of the README for how imperfect.
